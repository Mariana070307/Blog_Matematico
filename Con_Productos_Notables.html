Diferencia de cuadrados

Definición

Se trata del binomio formado por la resta de dos cuadrados perfectos. Al ser factorizado nos da como resultado el producto de dos binomios conjugados.

Representación:

  • a² - b² = (a + b)(a - b)

Pasos para resolver:

  1. Verificar que sea un binomio con signo de resta y que ambos términos sean cuadrados perfectos.
  2. Sacar la raíz cuadrada de cada término.
  3. Escribir el producto de dos binomios.

Ejemplo: 49x⁴ - 25y6

  1. Se verifica que es un binomio con signo de resta y que ambos términos son cuadrados perfectos.
  2. Se saca la raíz cuadrada de cada término: 7x² y 5y³.
  3. Se escribe el producto de dos binomios: (7x² + 5y³)(7x² - 5y³).

Resultado: (7x² + 5y³)(7x² - 5y³)

Binomio al cuadrado

Definición

Se trata de un binomio que se multiplica por sí mismo. Su factorización es un trinomio cuadrado perfecto.

Representación:

  • (a + b)² = a² + 2ab + b²
  • (a - b)² = a² - 2ab + b²

Pasos para resolver:

  1. Se eleva el primer término al cuadrado.
  2. Se multiplica el producto de los dos términos por 2.
  3. Se eleva el segundo término al cuadrado.

Ejemplo: (3x2 - 4y3)²

  1. Se eleva el primer término al cuadrado: (3x2)² = 9x4.
  2. Se multiplica el producto de los dos términos por 2: 2(3x2)(-4y3) = -24x2y3.
  3. Se eleva el segundo término al cuadrado: (-4y3)² = 16y6.

Resultado: 9x4 - 24x2y3 + 16y6

Comprobación:

Multiplicación Resultado
(3x2)² * (3x2)² 9x4
(3x2)² * (-4y3) -12x2y3
(-4y3) * (3x2) -12x2y3
(-4y3)² * (-4y3) 16y6

Trinomio cuadrado perfecto

Definición

Un TCP es un trinomio que se obtiene al elevar un binomio al cuadrado. Su factorización es el binomio elevado al cuadrado.

Representación:

  • a2 + 2ab + b2 = (a + b)2
  • a2 + 2ab + b2 = (a + b)2

Pasos para resolver:

  1. Se saca la raíz cuadrada del primer y tercer término.
  2. Se verifica que el segundo término sea el doble producto de las raíces obtenidas.
  3. Se escribe el binomio elevado al cuadrado.

Ejemplo: 16x6 - 40x3y2 + 25y4

  1. Se saca la raíz cuadrada del primer y tercer término: √(16x6) = 4x3 y √(25y4) = 5y2.
  2. Se verifica que el segundo término sea el doble producto de las raíces obtenidas: 2(4x3)(5y2) = 40x3y2.
  3. Se escribe el binomio elevado al cuadrado: (4x3 - 5y2)².

Resultado: (4x3 - 5y2)2

Comprobación:

Multiplicación Resultado
4x3 * 4x3 16x6

(-5y2) * (4x3) -20x3y2
(-5y2)² * (-5y2) 25y4
